# OS reference

The desktop shell, pixel icons, fonts, window controls, toolbar, drag/resize indicators,
and game integrations were adapted from https://github.com/henryjeff/portfolio-inner-site.
The original application used Create React App, React 17 and TypeScript. This version
runs inside Next.js with React 19, and uses a MemoryRouter so navigation stays within
the monitor without changing the host portfolio URL.

Personal portfolio pages now use the verified content in src/data/portfolio.js.
No résumé, degree/graduation date, location or availability is claimed without input.
The contact form opens a mailto draft; it does not submit to the reference author's server.
The original models, textures and sounds are credited in the OS Credits application.
The 3D reference's license is retained at src/lib/room/LICENSE.md.
